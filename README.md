Dashboard Analítico: Locação de Veículos 

🚗📊 Repositório dedicado ao projeto prático de Business Intelligence focado na modelagem de dados e criação de relatórios gerenciais para o setor de locação de veículos.
📌 Sobre o Projeto Este projeto simula um cenário real de negócios onde bases heterogêneas (arquivos Excel e consultas via SQL Server) são tratadas, modeladas e transformadas em um painel executivo para monitoramento de faturamento, consumo de quilometragem e comportamento de clientes.

🛠️ Principais Tecnologias e Habilidades Aplicadas
Power BI Desktop: Construção de relatórios e painéis interativos.

Power Query (ETL): Limpeza de dados, tratamento de erros de datas/formato, substituição de strings, divisão de colunas por delimitadores e unificação de tabelas.

SQL & Modelagem Relacional: Aplicação de Inner Joins, Left Joins e Left Anti Joins, além do gerenciamento de relacionamentos e cardinalidades.

Linguagem DAX: Criação de colunas calculadas e medidas de alta performance (como SUMX, DISTINCTCOUNT e segmentações dinâmicas).

Data Visualization: Uso de visuais certificados, formatação condicional baseada em regras e recursos analíticos de projeção de séries históricas.

⚙️ Estrutura do Projeto
Tratamento e Qualidade: Higienização de dados brutos de frotas e clientes.

Métricas de Faturamento: Análises por ano, mês, dia (drill down) e percentual do total.

Segmentação Comportamental: Identificação de clientes ativos/inativos e análise de ticket médio.

Feito com dedicação por Gabriela Custódio.
